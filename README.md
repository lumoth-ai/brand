# Lumoth Brand Assets

The Lumoth logo — a moth flying toward light, from *Lumen* (light) + *Moth*.

| File | Use |
| --- | --- |
| `logo/lumoth-logo.svg` | Full colour, transparent background. Preferred everywhere. |
| `logo/lumoth-logo-512.png` · `-1024.png` | Raster fallback, transparent background. |
| `logo/lumoth-logo-black.svg` · `.png` | One colour, for light backgrounds. |
| `logo/lumoth-logo-white.svg` · `.png` | One colour, for dark backgrounds. |
| `logo/*-1024.jpg` · `*-2000.jpg` | For places that reject SVG or PNG (print, some
submission forms). JPG cannot be transparent: the colour and black files come on
white, the white file on black. Prefer SVG or PNG everywhere else. |

## Using the logo

You may use these files, unmodified, to refer to Lumoth and its projects — in
articles, talks, package listings, link buttons and the like.

Please:

- **Keep clear space** around the mark of at least 25% of its width.
- **Do not stretch, rotate, recolour or redraw it**, or add effects.
- **Do not put the colour version on a busy or mid-tone background** — use the
  one-colour version instead.
- **Keep it legible**: 24px is the smallest recommended size on screen.
- **Do not use it as your own app icon, avatar or product mark**, or in any way
  that suggests Lumoth endorses, sponsors or is affiliated with your project.

there, ask first.
