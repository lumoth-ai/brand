# Lumoth 品牌素材

[English](README.md) · **简体中文**

Lumoth 标识，取 *Lumen*（光）＋ *Moth*（蛾）之意，寓意飞蛾向光。

| 文件 | 用途 |
| --- | --- |
| `logo/lumoth-logo.svg` | 彩色，透明底。优先使用这个。 |
| `logo/lumoth-logo-512.png` · `-1024.png` | 位图版本，透明底。 |
| `logo/lumoth-logo-black.svg` · `.png` | 单色，用于浅色背景。 |
| `logo/lumoth-logo-white.svg` · `.png` | 单色，用于深色背景。 |
| `logo/*-1024.jpg` · `*-2000.jpg` | 供不接受 SVG 和 PNG 的场合使用（印刷、部分提交表单）。JPG 不支持透明：彩色版与单色黑配白底，单色白配黑底。其他场合请优先用 SVG 或 PNG。 |

## 使用规范

在指代 Lumoth 及其项目时（文章、演讲、软件源收录、链接按钮等），可以原样使用这些
素材。

请注意：

- **留白**：标识四周留出不少于其宽度 25% 的空间。
- **不要拉伸、旋转、改色或重绘**，也不要添加效果。
- **不要把彩色版放在花哨或中间色调的背景上**，这类背景请改用单色版。
- **保证清晰可辨**：屏幕上建议最小尺寸为 24px。
- **不要把它用作你自己的应用图标、头像或产品标识**，也不要以任何方式暗示 Lumoth
  对你的项目存在认可、赞助或合作关系。

完整条款见 [LICENSE.md](LICENSE.md)。超出上述范围的使用、合作或授权咨询，请先发
邮件至 <support@lumoth.com>。
